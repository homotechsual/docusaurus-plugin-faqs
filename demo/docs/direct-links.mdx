# Direct Links

Each FAQ entry has an anchor you can share as a link to that question.

## How slugs are derived

The plugin turns the question text into a URL slug:

1. Convert to lowercase
2. Remove characters other than letters, digits, whitespace, underscores, and hyphens
3. Trim leading and trailing whitespace
4. Replace spaces and underscores with hyphens
5. Collapse runs of hyphens to a single hyphen

For example: `"How do I reset my password?"` → `how-do-i-reset-my-password`

## Duplicate slug disambiguation

If questions produce the same slug, the plugin adds a suffix: `-2` for the second, `-3` for the third, and so on. It assigns slugs in file read order, which is alphabetical by filename.

## The permalink icon

Hover over a question to see its `#` link. Click the link to update the address bar with that question's URL fragment.

## Auto-expand on load

When someone opens a FAQ URL with a fragment, such as `/faqs#how-do-i-reset-my-password`, the matching entry opens and scrolls into view. The same happens when navigating to a fragment from another page on the site.
