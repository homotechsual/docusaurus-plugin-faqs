# Writing FAQ Entries

Each FAQ entry is a single YAML file inside the configured `path` directory. Both `.yaml` and `.yml` extensions are recognised. Files are read in alphabetical order by filename.

## File format

```yaml
question: How do I reset my password?
answer: |
  Open the **sign in** page and select *Forgot password*. You'll receive
  an email with a link to choose a new one.
category: Accounts
order: 1
```

## Field reference

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `question` | `string` | Yes | The question text, shown as plain text |
| `answer` | `string` | Yes | The answer, parsed as Markdown by [marked](https://github.com/markedjs/marked) |
| `category` | `string` | No | Groups questions under a heading. Entries without a category appear under **General** and are sorted last |
| `order` | `number` | No | Sorts entries within a category. Lower numbers appear first. Entries without an order follow ordered entries and are sorted alphabetically by question |

## Sorting behaviour

1. Categories are sorted alphabetically.
2. Within a category, entries with an explicit `order` come first (ascending).
3. Remaining entries within a category are sorted alphabetically by `question`.
4. Entries without a `category` are collected under **General** and placed after all named categories.

## Skip behaviour

Files with invalid YAML or without string `question` and `answer` fields are skipped. The plugin prints a warning during the build and continues.
